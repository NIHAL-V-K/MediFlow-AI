# MediFlow AI

An AI-powered touchless medical screen navigation system that uses hand gesture recognition to control medical images without physical contact.

## Features

- Hand gesture recognition
- Touchless navigation
- Next image
- Previous image
- Zoom in
- Zoom out
- Pointer control

## Technologies Used

- Python
- OpenCV
- MediaPipe
- TensorFlow
- NumPy
- Flask

## Gestures

| Gesture | Action |
| --- | --- |
| 1 Finger | Pointer |
| 2 Fingers | Next Image |
| 3 Fingers | Previous Image |
| Closed Hand | Zoom In |
| 5 Fingers | Zoom Out |
